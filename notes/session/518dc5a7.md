## 🤖 Assistant

To SSH into a running Alpine QEMU VM, you need to set up port forwarding. Here are the common approaches:

## 1. User-mode networking with port forwarding

Add this to your QEMU command line:
```bash
-nic user,hostfwd=tcp::2222-:22
```

Then SSH from host:
```bash
ssh -p 2222 root@localhost
```

## 2. If QEMU is already running

Check if port forwarding was configured. Look at your launch command for `-hostfwd` or similar options.

## 3. Inside Alpine - ensure SSH is running

```bash
# Install and start SSH
apk add openssh
rc-update add sshd
service sshd start

# Allow root login (if needed)
echo "PermitRootLogin yes" >> /etc/ssh/sshd_config
service sshd restart
```

## 4. Alternative: QEMU monitor

If you have access to the QEMU monitor (Ctrl+Alt+2 or `-monitor stdio`), you can add port forwarding at runtime:
```
hostfwd_add tcp::2222-:22
```
